# PROMARKET_CHATS

Repositorio de conversaciones reales de WhatsApp para ProMarket Ecuador.

**Propósito:** Registrar, analizar y aprender de cada chat para mejorar el cierre de ventas.

---

## Estructura

```
CHATS/          → Transcripciones completas de conversaciones
SESIONES/       → Resúmenes operativos por día de trabajo
ANALISIS/       → Patrones, errores y aprendizajes extraídos
```

## Reglas del repo

- Cada chat nuevo va en `CHATS/` con nombre: `YYYY-MM-DD_nombre-o-numero.md`
- Cada sesión de trabajo va en `SESIONES/` con nombre: `YYYY-MM-DD.md`
- `ANALISIS/patrones.md` se actualiza cuando hay aprendizaje nuevo
- `ANALISIS/errores.md` registra errores detectados y su corrección
